# Licensing

DOTS Family Mode is offered under two routes:

1. **GNU Affero General Public License v3 or later (AGPL-3.0-or-later)** — the
   licence declared by the workspace (`Cargo.toml`) and the default for anyone
   who receives the software.
2. **Commercial licence** — a separate written agreement for closed-source or
   proprietary deployment, negotiated case by case.

The full terms are in [LICENSE](LICENSE), which contains the canonical
AGPL-3.0 text. That file is the licence; this file is only a summary.

## AGPL-3.0-or-later

You may use, modify and redistribute the software under the AGPL. If you run a
modified version and let other people use it over a network, the AGPL requires
you to offer them the complete corresponding source code under the same
licence. The AGPL also includes a patent grant in section 11.

Contact for AGPL questions: licensing@dots-family-mode.org

## Commercial licence

A commercial licence is for organisations that want to deploy the software in
a closed-source product, or that cannot meet the AGPL source-availability
requirements.

Contact for commercial licensing: shift@someone.section.me

Include your company name, the intended use case and a description of the
deployment. Commercial licences are granted case by case; terms and fees are
set in the written agreement.

## Choosing a route

Use the AGPL when you:

- want to modify and redistribute the software;
- are deploying it as a service or on a network; or
- are contributing to the open-source project.

Ask about a commercial licence when you:

- are building a closed-source product;
- do not want to distribute your modifications; or
- are embedding the software in a proprietary system.

## Source file headers

The AGPL text in [LICENSE](LICENSE) does not itself name the copyright holder.
Individual source files may carry their own copyright and licence headers.
